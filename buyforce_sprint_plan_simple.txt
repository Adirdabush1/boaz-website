BuyForce MVP – חלוקה ל-6 בעלי תפקידים (ספרינטים דו-שבועיים)
אנשים:
1. רפאל – מוצר ואסטרטגיה
2. דנה – עיצוב UX/UI ותוכן
3. נועם – פרונט Web (Next.js)
4. שירה – מובייל (React Native)
5. איתמר – בקאנד ו-API (Nest.js + DB + תשלומים)
6. אלון – DevOps, CI/CD ו-QA

Sprint 0 (01-14.12.2025) – הקמה וסנכרון
• רפאל: לסגור את ה-PRD עם כל ההערות, לכתוב מטרות מספריות ל-KPI, לפתוח לוח מעקב במאנדי.
• דנה: לבחור צבעים ופונטים, להכין סט רכיבים ראשוני בפיגמה, לכתוב קופי קצר להסברי המוצר.
• נועם: להרים פרויקט Next.js בסיסי, לבדוק שהריפו מתחבר למונורפו, להכין שלד לניווט עליון.
• שירה: לפתוח את פרויקט React Native, להגדיר את הספריות (Navigation, SafeArea), לוודא build על iOS/Android.
• איתמר: להכין דיאגרמת ארכיטקטורה, להגדיר סכמת DB ראשונית ולקבע מודולים בנסט, לאסוף מפתחות ל-Tranzilla/Firebase/SendGrid.
• אלון: להקים מונורפו, לחבר GitHub Actions/Bitrise, להכין סביבות Local/Staging/Prod ולהחביא סודות.

Sprint 1 (15-28.12.2025) – זהות משתמש ו-Shell אפליקטיבי
• רפאל: לאשר טקסטים למסכי התחברות, לעבור על חוויית onboarding, לעדכן KPI לפי ההתקדמות.
• דנה: לעצב onboarding של 3 שקופיות, לבנות את ה-Header והניווט התחתון, לעצב מסך פרופיל בסיסי.
• נועם: לפתח מסכי הרשמה/התחברות ב-Web, לחבר את הניווט העליון+תחתון, להציג פרטי משתמש במסך פרופיל.
• שירה: לפתח onboarding ו-login ב-RN, לחבר bottom tabs, להראות פרטי משתמש באפליקציה.
• איתמר: לבנות מודול Auth (Firebase JWT Guard), להרים /auth/login,/register,/user/me,/user/settings וזרימת Forgot Password.
• אלון: להוסיף בדיקות Cypress/Detox לזרימות הכניסה, לחבר לוגים ואירועים (Mixpanel/GA4) עבור onboarding ו-login.

Sprint 2 (29.12.2025-11.01.2026) – קטלוג, דף בית וחיפוש
• רפאל: לבחור רשימת קטגוריות MVP, לאשר קופי לדף הבית, לבדוק נתונים לדפי מוצר.
• דנה: לעצב גריד קטגוריות, כרטיס מוצר פשוט, מסך Wishlist, וחיפוש במסך מלא עם מצבי ריק.
• נועם: להוסיף /categories ו-feed ב-Web, לפתח דף בית דינמי, דף מוצר עם קרוסלת תמונות, Wishlist ו-Search overlay.
• שירה: להציג קטגוריות, דף בית בסיסי ו-Wishlist ב-RN, להוסיף קומפוננטת חיפוש עם הצעות.
• איתמר: ליצור טבלאות categories/products/wishlist, לבנות /categories,/products,/product/:id,/wishlist,* /search/suggestions, ולהוסיף קאש ב-Redis לדף הבית.
• אלון: למדוד את זמני התגובה (יעד <300ms), לעדכן ניטור בסיסי ל-APIs החדשים ולוודא deploy מסונכרן.

Sprint 3 (12-25.01.2026) – קבוצות וזרימת "הצטרף בשקל"
• רפאל: להגדיר כללי קבוצה (יעד, נעילה, הודעות), לאשר קופי לטעויות תשלום וקבוצה מלאה.
• דנה: לעצב כרטיסי קבוצה, מסך פרטי קבוצה, מודל אישור הצטרפות ומצבי שגיאה.
• נועם: להוסיף כפתור "Join" בדף מוצר, לפתח דף פרטי קבוצה ו"הקבוצות שלי" ב-Web, לטפל במסרים (Joined✔ וכו').
• שירה: לבנות את אותו flow במובייל, להראות טאבים Active/Closing/Charged וכו'.
• איתמר: ליצור טבלאות groups ו-group_memberships, לפתח שירות סטטוסים, API /group/join,/group/:id,/user/groups ולהרים Scheduler לזמני DEADLINE.
• אלון: להוסיף בדיקות אינטגרציה להצטרפות, לנטר חריגות בתורים ולהגדיר התראות אם סטטוס תקוע.

Sprint 4 (26.01-08.02.2026) – תשלומים ונוטיפיקציות
• רפאל: לתאם עם Tranzilla את כל הטסטים, לאשר טקסטים לנוטיפיקציות (70%, 95%, כישלון).
• דנה: להכין תבניות Push/Email/מסך נוטיפיקציות, לעצב מסך פנימי לנוטיפיקציות.
• נועם: להציג שגיאות תשלום בדפי מוצר/פרופיל, לפתח מרכז נוטיפיקציות ב-Web.
• שירה: להציג סטטוס תשלום במובייל, להוסיף מסך נוטיפיקציות וגלישה לעומק מתוך פוש.
• איתמר: לחבר Tranzilla (preauth, charge, refund), ליצור טבלת transactions, לבנות מודול נוטיפיקציות עם hooks לאירועים.
• אלון: להגדיר תורי BullMQ, לדאוג לסודות מאובטחים, להוסיף retry ו-logging לכל תשלום ונוטיפיקציה.

Sprint 5 (09-22.02.2026) – חוויית משתמש מתקדמת וחיפוש מלא
• רפאל: לבדוק ביטול הצטרפות מול מדיניות ספקים, לקבוע אילו אירועי אנליטיקס חובה, לוודא תרגומים.
• דנה: לעדכן מסכי ריק/הודעה, לעצב פילטרים, להכין קבצי i18n וגרסת Wishlist מלאה.
• נועם: להוסיף Cancel משתתף ב-Web, להרחיב חיפוש (מיון+פילטר), לשפר דף קבוצה לעדכונים חיים, להכניס i18n.
• שירה: אותם פיצ׳רים במובייל (חיפוש עשיר, ביטול, Wishlist מושלם, עדכון טיימר).
• איתמר: לחשוף /group/cancel,/search/results עם פילטרים, לשדר אירועי אנליטיקס ל-Mixpanel לכל הזרימות.
• אלון: להרחיב אוטומציית QA (Cypress/Detox) לפיצ׳רים החדשים, לוודא שהטלמטריה נאספת ושומרת SLA.

Sprint 6 (23.02-08.03.2026) – מובייל מלא, ביצועים ואבטחה
• רפאל: להכין קבוצת בטא, לנהל טפסי פידבק, לעדכן KPI לפני בטא.
• דנה: לתת תמיכה אחרונה במובייל (מצב ללא רשת, סקלטונים), להכין אססטים לחנויות.
• נועם: לשפר ביצועים ב-Web (קאשינג, Lighthouse>80), להוסיף מצבי Skeleton ו-handling ללא רשת.
• שירה: להשלים parity של Homepage/Category/Product/MyGroups במובייל, להוסיף Deep Links מפוש, לבדוק Offline.
• איתמר: להריץ בדיקות עומס (k6) למסלולי Join/Pay, להוסיף rate limiting ו-helmet, להשלים audit logs לאדמין.
• אלון: להקים Grafana/PagerDuty, להרחיב בדיקות CI, להריץ בדיקת חדירה בסיסית ולתעד.

Sprint 7 (09-22.03.2026) – אדמין, אנליטיקה והשקה
• רפאל: להכין פלייבוק השקה, לאשר דוחות אנליטיקה, להוביל תהליך עלייה לאוויר.
• דנה: לעצב מסכי אדמין בסיסיים (מוצר/קבוצות), להכין חומרים שיווקיים להשקה.
• נועם: לפתח ממשקי אדמין למוצר וקבוצות ב-Web, לבצע תיקוני UI אחרונים.
• שירה: לבצע תיקוני באגים, להכין buildים ל-App Store/Play Store ולהגיש.
• איתמר: לחשוף APIs לאדמין (מוצרים, קבוצות, ספקים), להכין דוח התאמת תשלומים יומי.
• אלון: להריץ מצבי חירום (Runbook), להפעיל on-call, לוודא שכל הניטורים וההתראות עובדים ב-Prod.
